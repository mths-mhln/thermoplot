Configuration file¶

A diagram is fully described by one configuration file in the INI format. This page lists every setting, its type, its allowed values and its unit.

File format¶

[THERMOPLOT SETTINGS]

; comment lines start with ; or #
diagram_type = TS
fluid_name = CO2
S_range = [500, 2250]

  • All settings belong to the single section [THERMOPLOT SETTINGS].

  • Keys are case-sensitive: write S_range, not s_range.

  • Comments must stand on their own line. A comment after a value becomes part of the value.

  • Values are converted as follows:

text in square brackets, separated by commas

Settings¶

Every setting below must be present; the file is rejected otherwise. The comments in the example files mention defaults, but Thermoplot does not fill in missing settings.

Allowed values

diagram_type

str

TS, PH

Diagram type: temperature against entropy, or pressure (logarithmic) against enthalpy. Upper case.

fluid_name

str

a fluid name in the CoolProp convention that REFPROP knows, e.g. CO2, R1234ze(E), Water

show_isolines

bool

True, False

Draw the isolines of quality and the two isoline families of the diagram. With False, only the saturation dome, the critical point and the critical isoline remain.

show_critical_point

bool

True, False

Required, but not used in version 0.1.0: the critical point is always drawn.

show_critical_isoline

bool

True, False

Required, but not used in version 0.1.0: the critical isoline is always drawn.

show_spinodal

bool

True, False

Required, but not used in version 0.1.0: spinodal curves are not yet implemented.

n_pts

int

2 or more; 400 in the examples

Number of points per isoline. The saturation dome uses twice as many. More points give smoother lines and take longer.

latex_formatting

bool

True, False

Typeset all text with LaTeX. Requires a LaTeX installation and makes interactive windows slower.

Depending on diagram_type, two range settings are also required. Each is a list of a lower and an upper bound.

The ranges set the axis limits, and also decide which isolines are drawn: the isenthalps of a T–s diagram and the isentropes of a p–h diagram are spread over the enthalpy or entropy range found inside the window (What is drawn).

Validation¶

When the file is read, Thermoplot checks that

  1. the section [THERMOPLOT SETTINGS] exists, otherwise it raises ValueError: Missing 'THERMOPLOT SETTINGS' section in config file;

  2. diagram_type is present, otherwise ValueError: Missing necessary thermoplot setting: diagram_type;

  3. all settings required for the diagram type are present, otherwise ValueError: Missing necessary thermoplot settings in config file: [...], listing the missing keys.

Types and values are not checked. A diagram_type other than TS or PH passes the checks but fails later, and ranges outside the validity of the fluid (for example below its triple point) simply leave parts of the diagram empty. Settings that Thermoplot does not know are read without error and ignored.

Choosing the ranges¶

Good ranges enclose the saturation dome and the states of the processes you want to plot. CoolProp gives the reference values:

import CoolProp.CoolProp as CP

fluid = "CO2"
T_triple = CP.PropsSI("Ttriple", fluid)
T_crit, p_crit = CP.PropsSI("Tcrit", fluid), CP.PropsSI("Pcrit", fluid)
s_liquid = CP.PropsSI("S", "T", 1.02 * T_triple, "Q", 0, fluid)   # left edge of the dome
s_vapour = CP.PropsSI("S", "T", 1.02 * T_triple, "Q", 1, fluid)   # right edge of the dome
print(f"T_range = [{1.02 * T_triple:.0f}, {1.15 * T_crit:.0f}]")
print(f"S_range = [{0.9 * s_liquid:.0f}, {1.05 * s_vapour:.0f}]")

Keep the lower temperature above the triple-point temperature: the saturation dome ends there, and the equations of state do not describe solid states.

Example files¶

The repository contains two T–s configurations, and this documentation adds a p–h configuration:

config/R1234ze(E).ini¶
[THERMOPLOT SETTINGS]

; Diagram type - [ TS / PH ]
diagram_type = TS

; Name of the fluid whose thermodynamic diagrams are to be plotted. Name follows the CoolProp naming convention.
fluid_name = R1234ze(E)

; Show fluid spinodal curve - [ True / False ] - Default: False
show_spinodal = False

; show fluid isolines - [ True / False ] - Default: True
show_isolines = True

; show critical point - [ True / False ] - Default: True
show_critical_point = True

; show critical isoline - [ True / False ] - Default: True
show_critical_isoline = True

; Thermodynamic region of interest 
; Either P_range = [P_min, P_max], H_range = [H_min, H_max]
; or     S_range = [S_min, S_max], T_range = [T_min, T_max]
S_range = [1000, 1800]    
T_range = [250, 400]  
; P_range = [1e3, 1e7]
; H_range = [5e4, 5e5]

; number of points per isoline.
n_pts = 400

; apply latex formatting to the figure - [ True / False ] - Default: True
latex_formatting = False
docs/examples/CO2_PH.ini¶
[THERMOPLOT SETTINGS]

; Diagram type - [ TS / PH ]
diagram_type = PH

; Name of the fluid whose thermodynamic diagrams are to be plotted. Name follows the CoolProp naming convention.
fluid_name = CO2

; Show fluid spinodal curve - [ True / False ]
show_spinodal = False

; show fluid isolines - [ True / False ]
show_isolines = True

; show critical point - [ True / False ]
show_critical_point = True

; show critical isoline - [ True / False ]
show_critical_isoline = True

; Thermodynamic region of interest: pressure in Pa, enthalpy in J/kg
P_range = [6e5, 2e7]
H_range = [8e4, 5.2e5]

; number of points per isoline.
n_pts = 400

; apply latex formatting to the figure - [ True / False ]
latex_formatting = False
